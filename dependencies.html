    Description: Clirr is a tool that checks Java libraries for binary and source compatibility with older releases. The clirr-maven-plugin can be configured to break the build, if it detects incompatible api changes. In a continuous integration process, the clirr-maven-plugin can automatically prevent accidental introduction of binary or source compatibility problems.
